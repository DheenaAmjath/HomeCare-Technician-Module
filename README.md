# HomeCare Technician Module

**Technician Service Management | HCI Group Project | SLIIT**

## 📌 Project Overview

HomeCare Reminder is a mobile application developed as part of a group project for the Human-Computer Interaction (HCI) module. It aims to simplify home appliance maintenance, service management and repair tracking.

This repository showcases my individual contribution to the Technician Service Management module.

## 🎯 Module Objectives

- Enable technicians to view customer service requests.
- Display appliance information and reported problems.
- Allow technicians to update repair status.
- Maintain repair history for completed services.

## ✨ My Individual Contribution

As a team member, I contributed to the Technician Service Management module.

My work included:

- Technician dashboard
